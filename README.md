# Tapety Studio — Marek Zettel | Cyfrowy Przyjaciel

**Wersja 2.0.0** · [Pobierz ZIP (release)](https://github.com/zetmar-collab/Tapety-Studio/releases/latest)

PWA z 250 gotowymi promptami do generowania tapet AI (125× 16:9 desktop + 125× 9:16 telefon).

## Użyj online (bez instalacji)

Aplikacja działa w przeglądarce (GitHub Pages):

**https://zetmar-collab.github.io/Tapety-Studio/**

Nie potrzebujesz lokalnego serwera HTTP.

Repozytorium: **https://github.com/zetmar-collab/Tapety-Studio**

## Szybki start (lokalnie)

**Windows:** `scripts\setup-windows.bat`  
**macOS:** `./scripts/setup-macos.sh`  
**Linux:** `./scripts/setup-linux.sh`

Szczegóły: `scripts/PIERWSZE-URUCHOMIENIE.txt`

## Funkcje

- **Stwórz tapetę** (menu główne → osobne okno) — format 16:9 / 9:16, styl, opis + wyślij do AI
- Wyszukiwarka i filtry kategorii (minimal, anime, cyberpunk, natura…)
- Paginacja listy (szybsze ładowanie)
- Kopiuj do schowka · Modyfikuj z AI (zapamiętany model) · Generator obrazu
- Wylosuj prompt
- Banner PrompBase po kilku akcjach
- Onboarding 3 kroki · PWA offline
- Analityka: opcjonalnie [Plausible](https://plausible.io) — dodaj skrypt w `index.html`
