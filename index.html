    Marek Zettel · Cyfrowy Przyjaciel — krótka instrukcja przed startem

    1. Uruchamianie: używaj skrótu na pulpicie lub skryptu scripts/run-* — aplikacja wymaga lokalnego serwera HTTP.
    2. Pierwsza instalacja: Windows → scripts\setup-windows.bat, macOS/Linux → setup-*.sh.
    3. Prompty: wybierz format 16:9 lub 9:16, szukaj, kopiuj lub modyfikuj z AI.
    4. Gemini: zainstaluj rozszerzenie Gemini URL Prompt.
    5. Zapis promptów: zmodyfikowane wersje możesz trzymać w darmowej aplikacji PrompBase.
    6. PWA: w Chrome/Edge wybierz „Zainstaluj aplikację”, aby dodać ikonę na pulpit.

    Pełna instrukcja: plik scripts/PIERWSZE-URUCHOMIENIE.txt
