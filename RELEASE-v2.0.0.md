## Tapety Studio v2.0.0

### Nowości
- **Menu główne:** Stwórz tapetę · Biblioteka promptów · Wylosuj prompt
- **Okno „Stwórz tapetę”:** format 16:9 / 9:16, styl (realistyczne, ilustracja, anime), opis + wyślij do AI
- **250 promptów** z kategoriami, paginacją i wyszukiwarką
- **Modyfikuj z AI** — kopiowanie do schowka dla wszystkich modeli (Qwen, DeepSeek, Meta itd.)
- **Generator obrazu** — szybkie otwarcie Copilot / Leonardo / Ideogram
- Banner **PrompBase**, onboarding 3 kroki, PWA offline
- **GitHub Pages:** https://zetmar-collab.github.io/Tapety-Studio/

### Instalacja z ZIP
1. Rozpakuj archiwum
2. Windows: uruchom `scripts\setup-windows.bat`
3. Otwórz przez skrót na pulpicie lub skrypt `scripts\run-windows.bat`
4. Alternatywnie: użyj wersji online (link powyżej)
